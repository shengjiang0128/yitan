# 一摊

微信小程序「一摊」项目仓库。

## 前端同学请看

小程序代码在 **`前端/`** 文件夹内。

```bash
git clone https://github.com/shengjiang0128/yitan.git
```

**导入方式（二选一）：**

1. **推荐**：微信开发者工具 → 导入 **`yitan` 仓库根目录**（根目录 `project.config.json` 已配置 `miniprogramRoot: 前端/`）
2. 或直接导入 **`yitan/前端`** 文件夹

详细说明见 [`前端/README.md`](./前端/README.md)
