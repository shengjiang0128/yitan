# 一摊

微信小程序「一摊」项目仓库。

## 目录说明

| 目录 | 说明 |
|------|------|
| **`前端/`** | **前端交接包**，含小程序全部页面、组件、资源与 API 文档，可直接导入微信开发者工具 |
| `cloudfunctions/` | 微信云函数（登录等） |
| `scripts/` | 开发脚本（图标处理等） |
| `docs/` | 项目文档（根目录副本，交接请以 `前端/docs/` 为准） |

## 前端同学请看

请进入 [`前端/`](./前端/) 文件夹，阅读其中的 [README.md](./前端/README.md) 开始开发。

```bash
# 克隆后，用微信开发者工具导入「前端」文件夹即可
```
